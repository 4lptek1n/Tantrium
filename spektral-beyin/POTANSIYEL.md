## Katman 1 — Türev yetenekler (organların birleşimi)

### A. Analitik (veriden bilgi çıkar)
1. **Anomali tespiti** ✅ — yasa-artığı σ patlaması. Fibonacci'de 1 bozuk terim → σ 2e14× büyür. *Birleşim:* yasa-avcısı + eşik. Kullanım: sahtecilik, sensör arızası, veri bütünlüğü.
2. **Değişim noktası / SINIR** 🟡 — kayan pencerede yasa uydur; yasa/σ nerede kırılıyor = sınır. *Birleşim:* yasa-avcısı × pencere + akış(dim 69-71). **Projenin başladığı yer (Tantrium Boundary): spektral versiyonu.**
3. **Benzerlik arama** ✅ — coord_91 embedding + facet mesafe kNN. *Birleşim:* kodla + köprü. Domain-agnostik "buna benzeri bul".
4. **Sınıflandırma / taksonomi** 🟡 — coord_91 + etiket; büyük beyin (40k) sorgu. *Birleşim:* kodla + kNN/küme.
5. **Kümeleme** 🟡 — coord_91 uzayında yapısal gruplama (etiketsiz). *Birleşim:* kodla + k-means/spektral küme.
6. **Nedensellik / yönlülük** 🔵 — akış(dim 71) faz yönü + Q; hangi mod sürüklüyor. *Birleşim:* dinamik + manipüle.

### B. Üretken / dönüştürücü (nesne üret/değiştir)
7. **Çok-adım tahmin** ✅ — yasa açılımı N adım. Lucas 8→4 tam. *Birleşim:* yasa + ouroboros-genişlet.
8. **Veri tamamlama / imputation** 🟡 — eksik terimli diziye yasa uydur, boşluk doldur. *Birleşim:* yasa-avcısı (holdout mantığı ters).
9. **Süperçözünürlük** 🔵 — spektrumdan ara-değerler; sürekli açılım. *Birleşim:* mod uzayı + kesirli k.
10. **Gürültü ayıklama** 🟡 — düşük-SNR modları at, güçlü modlardan kur. *Birleşim:* dualite(rezonans) + toplamsal_kur.
11. **Kayıpsız codec** 🟡 — sıkıştır(yasa+seed) + aç; oran ölç, paketle. *Birleşim:* kodla + ouroboros.
12. **Evren morphing** 🔵 — A→B mod uzayında geçiş yolu (interpolasyon). *Birleşim:* manipüle × iki kimlik.
13. **Generatif örnekleme** 🔵 — bir sınıfın coord dağılımından yeni nesne. *Birleşim:* kodla-dağılımı + de_novo.

### C. Keşif (gizli yapı bul)
14. **Denklem keşfi (symbolic regression)** 🔵 — holonomik avcı; çok-değişkenliye genişlet. *Birleşim:* hiyerarsi + çok-boyut.
15. **Gizli periyot/frekans** ✅ — dualite toplamsal, tam frekans. *Birleşim:* dualite.
16. **Spektral kimlik keşfi (Connes)** ✅ — ham nesnenin gizli spektrumu; asal→zeta. *Birleşim:* dualite iki-yön.
17. **Evrensellik sınıfı** ✅ — GOE/GUE/Poisson; kaos mu düzenli mi. *Birleşim:* dualite.evrensellik.
18. **Metrik öğrenme** 🔵 — facet ağırlıklarını göreve göre ayarla. *Birleşim:* köprü + optimizasyon.

### D. Sistem / uygulama
19. **Zaman-serisi motoru** 🟡 — 2+7+10 birleşimi: tahmin+anomali+denoising tek API.
20. **Boundary/risk raporu** 🟡 — 2+1+7: sınır + sürücü + kapanış yolu (orijinal ürün, spektral).
21. **Çapraz-domain transfer** 🔵 — bir domainde öğrenileni köprüyle başkasına taşı.
22. **LLM köprüsü (ağız)** 🟣 — coord→düşünce-token→Gemma; GPU ister (Faz 4).

## İnşa sırası (değer × kolaylık)
1. **Değişim-noktası/SINIR** (#2) — projeyi kapatır, 1+2+7'yi birleştirir → BU TUR
2. Zaman-serisi motoru (#19) — tahmin+anomali+denoising paketi
3. Kayıpsız codec (#11) + imputation (#8) — ouroboros'un ürünleşmesi
4. Kümeleme+sınıflandırma (#4,5) — büyük beyin sorgu motoru
5. Symbolic regression çok-değişkenli (#14) — en zor, en değerli keşif
6. Morphing (#12) + generatif (#13) — manipülenin ürünleşmesi
