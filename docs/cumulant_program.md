# Log-Det Cumulant Program

## Central idea

Instead of proving each coefficient separately, write the normalized hidden factor as a log-det exponential series:

```text
H(t) = exp(L2*t + L4*t^2 + L6*t^3 + L8*t^4 + ...)
```

Then the ordinary coefficients are generated by cumulant combinations.

## First coefficient identities

```text
a1 = L2

a2 = L4 + L2^2/2

a3 = L6 + L2*L4 + L2^3/6

a4 = L8 + L2*L6 + L4^2/2 + L2^2*L4/2 + L2^4/24
```

## Why this matters

The coefficient positivity problem becomes a structure problem:

```text
Which cumulant combinations force coefficient positivity?
```

Some cumulants may be signed. The positivity appears to come from the full exponential recombination, not from naive termwise positivity of every cumulant block.

## v1 target

Build a cumulant atlas for:

```text
L2, L4, L6, L8
```

and compare it against the coefficient atlas.

## Proof-search direction

The desired outcome is a domination or induction principle:

```text
positive lower cumulant structure + controlled signed remainders
=> all coefficient combinations are positive
```

This is still a program, not a proof.
