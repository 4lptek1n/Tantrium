# ell=2 multiplier-enriched shifted Delta cone result

## Target

Region C final lemmas:

```text
Lemma 1: S2 - D1 >= 0
Lemma 2: S4 + S2 - D1 - D3 >= 0
```

## New basis

Scalar shifted Delta columns were not enough. The enriched cone uses multiplier columns:

```text
binom(x,b) * Delta_family[r+5-s]
```

For Lemma 1 the basis used:

```text
binom(x,b) * Delta2[r+5-s]
```

For Lemma 2 the basis used:

```text
binom(x,b) * Delta4[r+5-s]
binom(x,b) * Delta3[r+5-s]
binom(x,b) * Delta21[r+5-s]
binom(x,b) * Delta2[r+5-s]
```

with nonnegative LP coefficients.

## Finite-window result

The multiplier-enriched cone is feasible for every tested row:

```text
r = 3..15
Lemma 1 feasible = yes
Lemma 2 feasible = yes
```

This is exactly the transition predicted by the failed scalar test: the missing positivity lives in binomial multipliers on shifted Delta families.

## Interpretation

This is the first successful Delta-cone certificate family for the two Region C lemmas in the tested window.

The scalar cone failed. The multiplier-enriched cone succeeds.

## Remaining symbolic extraction

The LP coefficients are feasible but not canonical; they are generated by a linear solver. The next step is to extract a stable sparse symbolic pattern from these certificates, preferably with rational coefficients and a fixed small set of shifted multiplier columns.

This is a finite-window certificate discovery, not yet a full all-r symbolic proof.
