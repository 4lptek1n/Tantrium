3. LGV route test

A naive path matrix with entries separable as binom(n,a)*binom(j-1,b) would force much lower rank or a simple product law in r and s. The observed C matrices have full rank relative to the visible active dimensions, so the naive one-path separable model does not match.

However, full rank is exactly what one expects from an LGV or Plucker expansion over many nonintersecting path families. Thus the LGV route is still the strongest route, but the correct network must be built from the Newton-sum moment blocks before taking the Hankel determinant.
