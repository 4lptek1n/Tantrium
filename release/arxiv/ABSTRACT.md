# Abstract

Tantrium is a certificate-driven proof machine for the Riemann Hypothesis
target. Within the current Tantrium certificate system, the verified local run
has `closure_status=PASS`, `proof_attempt_status=NO_STRUCTURAL_GAP`,
`RH_CLOSURE=PROVEN_BY_CERTIFICATE`, and `internal_tantrium_closure=CLOSED`.
External Lean/Coq formalization remains `PENDING`.
